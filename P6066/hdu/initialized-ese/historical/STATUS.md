# Superseded historical installation

<!-- copyright-holders: Salvatore Paxia -->

This preserves the earlier DKS outputs produced with MAME379a18d53df and their
original manifest/instructions. The claim that the historical keyboard is
required was based on a comparison that also changed printer presence. Current
MAME accepts DKS input using reset BASIC mode, unshifted letters and its
supported PR 6610 printer card. Use the current instructions and media in the
parent directory; this archive is retained as provenance, not a prerequisite.
